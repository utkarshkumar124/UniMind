# LPU Official Portal Directory

## Direct Answer
The central student ERP portal is **UMS (`https://ums.lpu.in/`)**, online live classes run on **MyClass (`https://myclass.lpu.in/`)**, official campus messaging runs on **LPU Live (`https://lpulive.lpu.in/`)**, admissions & refunds run on **LPUAdmit (`https://admission.lpu.in/`)**, and certificate requests use **`https://ums.lpu.in/lpuums/LoginNew.aspx?loginPage=ExtCert`**.

## Complete Portal Reference Table

| Portal / Platform Name | Official URL | Primary Purpose |
|---|---|---|
| **UMS (University Management System)** | https://ums.lpu.in/ | Master student ERP: attendance, timetable, RMS tickets, E-Notices, fee payment, exam admit cards, results, reappear/re-eval, hostel/transport. |
| **LPU Touch (Mobile App)** | Google Play: `ums.lovely.university` | Mobile access to attendance, timetable, E-Notices, results, RMS, and leave passes. |
| **MyClass** | https://myclass.lpu.in/ | Online teaching & virtual classroom portal for live lectures and class materials (uses UMS credentials). |
| **LPU Live** | https://lpulive.lpu.in/ | Official university real-time group messaging, faculty/class channels, and file-sharing app. |
| **Certificate Application Portal** | https://ums.lpu.in/lpuums/LoginNew.aspx?loginPage=ExtCert | Online applications for bonafide, transcript, migration, provisional, and character certificates. |
| **LPUAdmit (Admissions & Refund Tracker)** | https://admission.lpu.in/ | Application forms, scholarship dashboards, LPUNEST booking, Post-Admission Services & Fee Refund tracking. |
| **LPU Official Main Website** | https://www.lpu.in/ | Official university website, programmes, fees, academic calendars, schools, ICC/grievance links. |
| **LPU Happenings** | https://happenings.lpu.in/ | Campus news, event updates, fests, guest lectures, and achievements. |
| **Student Grievance Redressal** | https://www.lpu.in/student-grievance-redressal.php | SGRC members, Ombudsperson details, and OTP-verified public grievance submission form. |
| **LPU Online Programmes** | https://www.lpuonline.com/ (Adm: `admission.lpuonline.com`) | UGC-entitled Online degree portal (separate from regular Phagwara campus UMS). |
| **LPU Distance Education (DDE)** | https://www.lpude.in/ | UGC-DEB Open & Distance Learning portal (`1800-3001-1800`). |
| **LPU Alumni Association** | https://alumni.lpu.in/ | Alumni network, reunions, transcripts & verification requests. |
| **Mapmyaccess & KOHA OPAC** | Via UMS -> Library | 24x7 library catalogue search and off-campus access to IEEE, Springer, ProQuest, NDL, JSTOR. |
