# Academic Calendar & Holidays (Regular Programmes)

## Direct Answer
For the **2026–2027 Academic Session (Autumn Term / Term-I)** of Regular Programmes, classes start on **Monday, July 27, 2026**, Mid-Term Tests (MTT) run from **October 1 to October 9, 2026**, End-Term Examinations (ETE) run from **December 14 to December 30, 2026**, Results are declared on **Tuesday, January 12, 2027**, and **Spring Term (Term-II)** classes start on **Monday, January 11, 2027**.

### Programmes with Separate Academic Calendars
LPU publishes separate specialized calendars on `lpu.in` for: **MBA**, **B.Pharm. / M.Pharm.**, **LSAD (Architecture/Design)**, **Agriculture**, **BPT / MPT**, **Law**, and **Education**. Always confirm your exact programme calendar in **UMS -> Academic Calendar / E-Notice**.
